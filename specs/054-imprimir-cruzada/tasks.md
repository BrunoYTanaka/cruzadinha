## Phase 3: User Story 1 - Imprimir a cruzada em branco (Priority: P1) 🎯 MVP

**Goal**: "Imprimir" button opens the browser print dialog with a sheet that has source, date, empty numbered grid, clues and attribution, and nothing from the game.

**Independent Test**: open a puzzle, type letters, press "Imprimir", check the preview (or `emulateMedia({ media: 'print' })`): empty grid, clues, attribution, no site UI.

- [x] T003 [US1] Create `apps/web/src/features/game/components/print/PrintSheet/PrintSheet.tsx`: `PrintSheet({ puzzle }: { puzzle: Puzzle })`, rendered with `createPortal` into `document.body` with class `sheet`. Content: `h2` with `puzzleSourceNames[puzzle.source]` and `printDate(puzzle.date)`; grid as CSS grid `repeat(width, 1fr)` with `style={{ '--cols': puzzle.grid.width }}`, square cells, number in the corner, each `block` cell an `<svg>` with a black filled `rect`; two lists "Horizontais" and "Verticais" from `printClues`, item `número. dica (length)`; footer `attributionLine(puzzle)`. No prop for solution, cells, draft or marks. Lists use `ol`; the block svg is `aria-hidden`.
- [x] T004 [P] [US1] Create `apps/web/src/features/game/components/print/PrintSheet/PrintSheet.module.css`: `.sheet { display: none }`; inside `@media print`: `.sheet { display: block }`, `:global(body) > :not(.sheet) { display: none !important }`, fixed `#fff` background and `#000` text on `.sheet`, `:global(html)` and `:global(body)` (no theme tokens, so the dark theme prints white), `print-color-adjust: exact`.
