# Mockups do front

`design-system.html` é a referência visual do site (feature 062): fundamentos (cores, tipografia,
raios, foco), componentes e todas as telas, nos temas claro e escuro, com seletor de largura
(computador, 768 e 390 px). Abrir o arquivo no navegador. Não tem ligação com a API: textos, tempos,
datas e códigos são inventados.

A landing `/` segue o próprio mockup (`specs/050-landing-mockup/`) e a grade do tabuleiro segue as
regras das features do jogo. As divergências assumidas entre este arquivo e o site estão em
`specs/062-design-system/research.md`.

Os mockups anteriores (`game.html`, `library.html`, `finish.html`, da feature 010) foram substituídos
por este arquivo e continuam no histórico do git.
